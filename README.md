# Fama — Boletería Virtual

Sistema de preventa de covers y boletas para Fama MZL, Manizales.

## Estructura
- `server/` — Backend Iraca (Node/TypeScript) → Railway
- `web/` — Frontend Next.js (admin + público + scanner) → Vercel

## Dev
cd server && pnpm install && pnpm start   # :2436
cd web && pnpm dev                         # :3000
